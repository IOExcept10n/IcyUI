# Changelog

## 0.1.0-alpha.1

The first public alpha.

**Controls**

- Buttons, toggles, check boxes, sliders, progress bars, text boxes, combo boxes, list and tree views, tab controls,
  expanders, split panes, scroll viewers, windows and dialogs, a color picker and a property grid.
- Panels: `Grid` with spans, `StackPanel`, `WrapGrid`, and virtualizing lists.

**Markup**

- XML markup with resources, styles, visual states, control templates and standalone resource dictionaries.
- Theme files: `UseThemeFile` and `ExtendDefaultTheme`.

**Binding**

- Typed bindings, text-to-value conversion for two-way bindings with validation errors, and culture-aware number formats.

**Input**

- Mouse, keyboard, gamepad and touch (with a gesture recognizer), spatial focus navigation, focus scopes and drag and drop.
- UI scaling that follows the monitor's DPI, plus a user scale setting.

**Hosts and configuration**

- Stride 4.4 and MonoGame (DesktopGL and WindowsDX) integrations with one `UseIcyUI` entry point, a fluent configuration
  builder, system and bitmap fonts, and logging through `Microsoft.Extensions.Logging`.

**Localization**

- `{Localize}` in markup, gettext `.po` files, resource-based and dictionary localizers, and layered translations.

**Editor**

- Hot reload of markup, a design session that watches source files, and an in-game editor with panels, a property
  grid and an element tree.

**Docs**

- This site: concepts, controls, guides, a markup reference and the API reference.
