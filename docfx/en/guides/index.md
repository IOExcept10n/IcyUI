# Guides

Step-by-step guides for common tasks. Each builds something small and complete; the [Concepts](../concepts/index.md)
pages explain the ideas behind them.

- [Building a game menu](game-menu.md): a main menu, a pause menu and a settings page with Apply and Cancel, behind one
  frame with back history.
- [Custom controls](custom-controls.md): a `HealthBar` control with a template part, a markup name and a default look.
- [Custom themes](custom-themes.md): recolor the built-in theme with a game palette, or replace it with a whole theme file.
- [Hot reload and the in-game editor](hot-reload-and-editor.md): edit a page in your text editor or over the running game,
  in Debug builds only.
- [Gamepad-friendly UI](gamepad.md): focus on open, layouts the D-pad can walk, dialogs, and a switch for gameplay.
- [Localizing your game UI](localization.md): keys in markup, `.po` files, a language setting and community translations.
- [Writing an engine integration](engine-integration.md): what an engine provides to run IcyUI, using FNA as the target.
