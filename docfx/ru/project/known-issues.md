# Известные проблемы

## Платформы

- **MonoGame DesktopGL на Windows on ARM64 может зависать при выходе.** Окно закрывается, но процесс остаётся жить.
  Причина в графическом слое, который DesktopGL использует на этих машинах, а не в IcyUI. Stride и MonoGame на WindowsDX
  этот слой не используют.
- **На MonoGame DesktopGL нет касаний.** Настольный бэкенд движка никогда не сообщает о сенсорном вводе, поэтому жесты
  касаний работают только там, где движок доставляет касания (Stride; WindowsDX не проверен). Мышь работает везде.
- **Масштабирование интерфейса следует за DPI-осведомлённостью приложения.** Приложение Windows без `app.manifest` с
  PerMonitorV2 сообщает масштаб дисплея 1 и растягивается Windows, из-за чего интерфейс выглядит размытым на экране с
  высоким DPI. См. [Масштабирование](../concepts/scaling.md).

## Ограничения, с которыми можно столкнуться

- **Тема выбирается при запуске.** Переключать темы во время работы игры нельзя.
- **`{Localize}` в установщике стиля читается один раз**, при загрузке стиля, поэтому не следует за сменой языка. Ставьте
  его на элементы или в шаблон.
- **Локализованный текст пока не принимает аргументы.** Строки формата вроде `"Score: {0}"` заполняет ваш код.
- **Клавиши нельзя переназначить.** Клавиши навигации по фокусу фиксированы; см. [Ввод и фокус](../concepts/input-and-focus.md).
- **Кнопки X и Y геймпада** вызывают события «назад» и «вперёд», но `Frame` пока на них не реагирует.
- **Некоторые элементы пока не полностью управляются с клавиатуры:** пункты списка, заголовки вкладок и значение
  ползунка. Страница каждого элемента говорит, что он поддерживает.
- **Вложенные пути привязки** следуют только за источником привязки (контекстом данных); см.
  [Привязка данных](../concepts/data-binding.md).
