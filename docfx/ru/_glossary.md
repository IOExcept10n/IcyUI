# Глоссарий перевода (не публикуется)

Единые термины для русской документации. Исключён из сборки в `docfx.ru.json`.

**Правило:** идентификаторы кода, XML, имена типов и членов остаются на английском. Подписи в примерах кода тоже
остаются английскими (код одинаков в обеих версиях документации). Переводится только текст.

| English | Русский | Примечание |
|---|---|---|
| control | элемент управления | |
| element | элемент | |
| binding | привязка (данных) | |
| data context | контекст данных | `DataContext` в коде |
| template | шаблон | |
| style | стиль | |
| theme | тема | |
| markup | разметка | |
| layout | компоновка | не «разметка»: это слово занято под markup |
| panel | панель | |
| focus | фокус | |
| view model | модель представления | |
| command | команда | |
| canvas | Canvas | не переводится: это имя типа |
| overlay | оверлей | |
| package | пакет | |
| snippet / example | пример | |
| backend (MonoGame) | бэкенд | |
| Game Studio | Game Studio | не переводится |
| startup script | стартовый скрипт | `StartupScript` в коде |
