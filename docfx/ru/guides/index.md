# Руководства

Пошаговые руководства по типичным задачам. В каждом строится что-то небольшое и законченное; идеи, на которых оно
держится, объясняют страницы раздела [Концепции](../concepts/index.md).

- [Игровое меню](game-menu.md): главное меню, меню паузы и страница настроек с кнопками «Применить» и «Отмена» в одном
  фрейме с историей переходов назад.
- [Свои элементы управления](custom-controls.md): элемент `HealthBar` с частью шаблона, именем в разметке и внешним видом
  по умолчанию.
- [Свои темы](custom-themes.md): перекрасьте встроенную тему палитрой игры или замените её целым файлом темы.
- [Горячая перезагрузка и редактор в игре](hot-reload-and-editor.md): правьте страницу в текстовом редакторе или прямо в
  запущенной игре, только в Debug-сборках.
- [Интерфейс для геймпада](gamepad.md): фокус при открытии, компоновка, по которой можно ходить крестовиной, диалоги и
  переключатель для игрового процесса.
- [Локализация интерфейса игры](localization.md): ключи в разметке, файлы `.po`, настройка языка и переводы сообщества.
- [Написание интеграции с движком](engine-integration.md): что движок даёт для запуска IcyUI, на примере FNA.
