# Ресурсы и шрифты

IcyUI загружает файлы разметки, словари ресурсов, шрифты и изображения через единый конвейер ресурсов: вы запрашиваете
файл по пути и типу, и его читает импортёр для этого типа. Поверх него у шрифтов своя система: она находит шрифт по имени
семейства, импортирует его при первой необходимости и подставляет резервный, если найти не удалось.

`Configuration.Assets.Load<T>(path)` загружает файл и возвращает его как `T`:

- **Откуда:** пути отсчитываются от `DefaultAssetContext` конфигурации — папки сборки игры, если вы её не меняли.
  Установите для файла **Copy to Output Directory** в «Copy if newer», чтобы он оказался на месте во время работы.
- **Что:** с настройками движка по умолчанию сразу загружаются `UIElement` (разметка), `ResourceDictionary` (файл
  словаря ресурсов) и шрифты, а интеграция с движком добавляет текстуры. `LoadAsync<T>` загружает без блокировки.
- **Короткий путь:** `Canvas.LoadMarkup(path, viewModel)` загружает разметку, задаёт ей контекст данных и добавляет её
  на Canvas.

Отсутствующий файл приводит к исключению; файл разметки с ошибкой бросает `MarkupException` с указанием файла, строки и
столбца.

## Шрифты

Текст запрашивает шрифт по семейству, размеру и начертанию. <xref:Icy.Rendering.Fonts.FontSystem> находит его так:

1. уже импортированный шрифт: векторный — в любом размере, растровый — только в своём;
2. **системный шрифт** из папки шрифтов Windows, если системные шрифты включены (с настройками движка по умолчанию они
   включены); папка индексируется один раз, когда семейство впервые не находится среди импортированных;
3. **резервный шрифт**, если ничего не подошло. IcyUI один раз пишет в журнал предупреждение об этом семействе
   (событие 1001), и текст с ним рисуется резервным шрифтом или не рисуется вовсе, если резервного нет.

Текст без `FontFamily` использует <xref:Icy.Rendering.Fonts.FontSystem.DefaultFontFamily>: Segoe UI с настройками
движка по умолчанию или семейство, заданное через `WithDefaultFontFamily`.

### Векторные и растровые шрифты

IcyUI читает два вида файлов шрифтов:

| | Векторные (`.ttf`, `.otf`) | Растровые (BMFont `.fnt`) |
|---|---|---|
| Размеры | Любые: один файл подходит для любого `FontSize`. | Один: тот, в котором шрифт создан. Другие размеры его не находят. |
| Масштабирование интерфейса | Перерисовываются в масштабированном размере, поэтому текст остаётся чётким. | Растягиваются из своего изображения, как картинка: чёткие только при масштабе 1. |
| Стоимость | Каждый символ рисуется в текстуру при первом использовании в каждом размере. | Рисовать нечего: символы уже есть в изображении. |
| Подходят для | Большинства интерфейсов: текста, который масштабируется вместе с дисплеем и настройками игрока. | Пиксельных игр, интерфейса с фиксированным разрешением, рисованного или стилизованного вида. |

Растровый шрифт — это файл AngelCode BMFont (текстовый, XML или двоичный) вместе с изображениями страниц, созданный,
например, в BMFont или Hiero. Импортируйте его так же, как векторный; изображения страниц загружаются из той же папки:

[!code-csharp[](../../../sources/IcyUI.Docs.Snippets.Stride/Fonts.cs#bitmap-font)]

Текст, использующий его, должен запрашивать точно его размер — `size` из файла: `<TextBlock FontFamily="Pixel"
FontSize="16"/>` для шрифта размером 16 пикселей.

[!code-csharp[](../../../sources/IcyUI.Docs.Snippets.Stride/Fonts.cs#own-font)]

Имя семейства — то, что записано в самом файле шрифта, а не имя файла. Импортируйте файл один раз и используйте в любом
размере.

Не копируйте шрифты Windows в свою игру: их лицензия запрещает распространение. Шрифты под лицензией SIL Open Font
License, например Noto Sans или Inter, можно поставлять с любой игрой. В Linux и macOS нет Segoe UI, поэтому игра для
этих платформ всегда должна импортировать собственный шрифт.

### Только свои шрифты

Настройки движка по умолчанию включают системные шрифты. Игра, которая поставляет все свои шрифты, может их выключить:
тогда текст выглядит одинаково на любой машине, а забытый импорт проявляется предупреждением во время разработки, а не
прячется за случайно установленным шрифтом:

Сделайте одним из своих шрифтов и семейство по умолчанию: Segoe UI — системный шрифт. Ваша конфигурация выполняется

`Configuration.Fonts.DisableSystemFonts()`; уже найденные системные шрифты остаются загруженными.

## Типичные ошибки

- **Текст не появляется.** Проверьте журнал на предупреждение о шрифте (1001): имя семейства написано с ошибкой или
  шрифт не установлен и не импортирован. См. [Журнал и диагностика](logging-and-diagnostics.md).
- **Растровый шрифт не находится.** Текст запрашивает размер, в котором шрифт не создавался. Используйте точно его
  размер или векторный шрифт.
- **Файлы отсутствуют во время работы.** Файл, не скопированный в папку сборки, игра не найдёт; проверьте его
  настройку Copy to Output Directory.
- **Загрузка каждый кадр.** `Load` каждый раз читает и разбирает файл (если вы не открыли кэш через
  `AssetResolver.CreateScope`); загрузите один раз и сохраните результат.
